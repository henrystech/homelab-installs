# Homelab Installs Roadmap

This file keeps track of useful script ideas that are not built yet.

## Next Ideas To Revisit

| Folder idea | Purpose |
| --- | --- |
| `documents-stack` | Paperless-ngx stack for searchable documents, OCR, consume folders, and archive storage. |
| `photos-stack` | Immich stack for self-hosted photo backup and photo library management. |
| `password-stack` | Vaultwarden stack for a lightweight self-hosted password manager. |
| `maintenance-stack` | Update and cleanup helper for Docker Compose stacks, images, logs, and stale containers. |
| `migrate-docker-folder` | Helper to move older `/docker` installs to a cleaner standard such as `/opt/homelab`. |

## Rule

When one of these becomes a real installer folder, add it to the root `README.md` and leave any still-unbuilt ideas here.
